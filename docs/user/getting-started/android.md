Android 版处于早期测试阶段，支持 Android 8.0 及以上版本。安装包包含常用的 64 位真机版本和 x86_64 模拟器版本。

## 安装与启用

1. 在手机上打开 APK。若系统阻止安装，按提示允许当前文件来源安装未知应用。
2. 安装完成后打开「Yagami 输入法」。
3. 点击「启用输入法」，在系统输入法列表中打开青简。
4. 返回应用，点击「选择 Yagami 输入法」。
5. 在任意文本框中输入拼音，点击候选或按 `空格` 上屏。

Android 会提示第三方输入法可能读取输入内容。这是所有 Android 输入法启用时的系统提示。当前版本的拼音转换、候选与译词均在本机完成。

## 升级

直接安装签名相同、版本号更高的新 APK，即可覆盖升级。不要先卸载旧版；卸载会清除应用私有数据，并可能需要重新启用输入法。

若系统提示签名不一致，说明安装包不是同一发布来源，不能直接覆盖。确认安装包来源后再决定是否卸载旧版。

## 当前功能

当前版本支持全拼、候选译词（英语、日语或西班牙语）、中英切换、Shift、数字与常用符号页、退格、空格上屏、回车原样上屏和长按空格切换输入法。
退格键长按后会连续删除，松手即停止。没有正在输入的拼音时，多行输入框的 `换行` 键插入新行并保持键盘打开；
单行输入框则按应用要求执行发送、搜索或完成。
打开「Yagami 输入法」应用，可在启用与选择输入法按钮上方切换候选译词语言；下次唤起键盘时生效。
键盘候选栏右侧的「剪贴板」按钮会显示最近 50 条文字记录，点击一条即可粘贴。相同内容再次复制后会移到最前，
记录保存在应用私有数据中，可在「Yagami 输入法」应用里清空。
按键说明见 [按键与快捷键](keys.md)。候选翻页、滑动输入、语音输入和用户词频持久化尚未提供。
